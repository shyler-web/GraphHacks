# Learner is new to all three layers; goal is a deployed Track 02 demo

The learner self-reports being new to graph databases/Cypher, LLM agent memory concepts, and React/TypeScript. They built the repo's foundation via AI acceleration and have low conceptual clarity, but do not want extreme depth — they want enough to **engineer, debug, and direct AI** toward a functional, deployed Track 02 submission.

## Implications
- Skip proofs and theory; lead with "what to run, what to expect, how to tell if it's wrong."
- Every lesson must end in a runnable artifact (a command, a query, a running panel), not an abstraction.
- Favor debugging drills and "read the output" skills over derivations.
- Milestones should map 1:1 onto the five Track 02 key-focus points so progress is visible against the prize criteria.
