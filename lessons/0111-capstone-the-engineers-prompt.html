Why this matters

The whole series rests on one claim from 0101: you cannot prompt better than you can think. Prompt phrasing is a 5–10% lever; context and success criteria are 20–45% (10xdev.blog, 2026). So the series is not about prompts — it is about the engineering judgment that a prompt has to carry. Each of the ten lessons drills one habit on your real cockpit. This capstone is the retrieval copy: read it, then prove it on one task.

Keep the prompt playbook open while you build. When a task stalls, the fault is almost always a missing habit here — no exit criterion, wrong context, no verify line — not a badly-worded sentence.

The build loop you run every time

Every later lesson is the same six steps (0101). You own steps 1–3 and 5–6; the agent owns the middle.

  1. Plan — the next smallest thing, mapped to a Track 02 key-focus point.
  2. Spec — the five-point card, exit criterion first (0103).
  3. Context — inject the graph model, the real Cypher, the locked decisions; nothing else (0104).
  4. Build — one contract, one slice, at a chosen autonomy tier (0105, 0109).
  5. Verify — run the evidence; a step is not done until its check passes (0106, 0107).
  6. Commit — message records what, the decision, why, and the exit evidence (0110).

Do it — the capstone drill

Run the whole loop once, on one real task, without re-opening the lessons. The natural candidate is the task you have been avoiding: the first real FalkorDB write.

Take one Track 02 task end-to-end through all six steps.

  1. Plan + Spec: write the five-point card — what it builds, exit criterion, out of scope, locked decisions, verification command. Cross out any line that is not checkable.
  2. Context: list the always/on-demand/never buckets for this task; pull only the on-demand files with graphify query "…". Never paste the whole file.
  3. Build: write the contract first (signatures, no bodies), pick one slice, and assign an autonomy tier. Run it as a bounded builder.
  4. Verify: run the exit-criterion command. If it fails, run the 0106 loop — repro, three hypotheses, cheapest test — not a guess.
  5. Commit: commit with what was built, the decision, why, and the exit evidence. Keep the word decision in the message so git log --grep="decision" finds it.
  6. Score yourself: which of the seven habits was weakest this run? That is your next deliberate-practice rep.
The honest caveat (from 0101). No lesson makes you senior. Judgment is built by reps under a deadline, not by reading. This page is the compressed copy — the reps are on your repo.
