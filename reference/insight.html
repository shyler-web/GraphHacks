5 · Risks & gotchas (read before you build)

The simulation is load-bearing and tempting. Every feature has a fake version already running, so the demo "works" with zero FalkorDB. That is exactly the rule-3 trap. Once T4.2 lands, stopping FalkorDB must visibly break the app — that flip is the whole submission.

Ambiguous "the app" file. Until T0.2, an AI session can edit the root copy while you run src/. The graph already shows two App() nodes. Kill the ambiguity first.

INFERRED edges are not verified facts. 103 edges are model-reasoned (App() has 6). Treat the graph's structure as a map; verify the connections against running code.

Graph drift. After you wire real code, rebuild with graphify update . so the map tracks reality. Docs/HTML need an LLM pass (a key); code re-extracts automatically.
