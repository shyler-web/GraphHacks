2 · The three-tier trick (features 2–4 as one)

The winning move is showing episodic, semantic, and procedural memory as one connected graph — a Turn (episodic) links to an Entity (semantic) which links to a Workflow (procedural). Three separate stores look like three demos; one connected graph looks like a memory system.

See the proposed node/edge structure in the data model.

4 · Submission artifacts (rule 10)

  • Public source-code repository
  • README with setup instructions and the graph data model
  • The real Cypher queries / graph algorithms the product depends on (queries.cypher)
  • Demo video of the working project
  • Live deployment, or complete local setup instructions
  • The track you are entering (Track 02)
  • AI-assistant use disclosed (rule 11)

5 · De-scope (do NOT build)

Auth and billing · advanced graph algorithms (beyond shortest-path if used) · Track 01/03 features · mobile · production hardening · horizontal scaling. Every hour on these is an hour not spent proving a key-focus point.
